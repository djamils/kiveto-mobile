## Intent

**Problem:** The app is still the Flutter counter template: no theme, no UI kit, no router, no HTTP client wired to the generated Portal API client, no session, no error model and no French strings, so no slice (identity_access, document, patient/consultation/home, scheduling, client, requests, clinic_listing) can start. Milestone V4 (architecture §11): N concurrent 401s trigger exactly one refresh, gated layers at 100%.

**Approach:** Build the shared foundation of the D15 tree, with placeholder pages only: `shared/domain` (value objects, `Clock`, sealed `ApiFailure`, ids, idempotency key), `shared/presentation` (design tokens, Lucide icons, the shared UI kit of the mockup, async widgets, French formatters), `core/{errors,network,security,di}` (problem mapping, Dio chain with strict status, dev host, device id, auth `QueuedInterceptor` with single-flight refresh, file downloads, token storage, session), `app/{bootstrap,routing,theme}` (env, `ProviderScope`, go_router with the 5-tab shell and the `/invitation` deep link, `ThemeData`, a debug kit gallery), French l10n, Android/iOS identity, then hand the seams to the slices.

## Design Notes

### Shared domain (`lib/shared/domain/`, pure Dart, 100%)

- `Clock` -- `abstract interface class Clock { DateTime now(); }` (UTC instant). `SystemClock` lives in `core/di/` (rule 8).
- `ClinicInstant implements Comparable<ClinicInstant>` -- an instant plus the wire UTC offset (`DateTime.parse` drops it). `new(DateTime instant, Duration offset)` stores `instant.toUtc()`; offset whole minutes, |offset| ≤ 18 h (`ArgumentError`). `factory parse(String)` requires `Z` or `±HH:MM` (`FormatException` otherwise). Getters: `instant` (UTC), `offset`, clinic-local `year month day hour minute second weekday` (from `instant.add(offset)`), `LocalDate date`. `compareTo`/`isBefore`/`isAfter`/`isAtSameMomentAs` by instant; `==`/`hashCode` on instant **and** offset; `toIso8601String()` → `2026-11-04T10:30:00+01:00` (seconds, no fraction, `+00:00` for zero); `toString` = that.
- `LocalDate implements Comparable<LocalDate>` -- `new(year, month, day)` validated (`ArgumentError` for 2026-02-30); `factory parse('YYYY-MM-DD')` (`FormatException`); `weekday`, `compareTo`, `isBefore`, `isAfter`, `==`, `daysUntil(LocalDate)`, `addDays(int)`, `toIso8601String()`.
- `Money` -- `new(int minorUnits, String currency)`; currency `^[A-Z]{3}$` else `ArgumentError`; `==`, `hashCode`, `toString` (`6800 EUR`). Formatting is presentation.
- Ids (the convention, written in the hand-over): typed ids are **extension types over the wire string**, `extension type const ClinicId(String value) {}`, declared in the owning feature's `domain/` (`PetId` in `patient`), or in `shared/domain/` when several features share them (`ClinicId` now). Never parse or validate UUIDs client-side; wrap at the infrastructure boundary.
- `uuidV4([Random? random])` -- RFC 4122 v4 string from `Random.secure()` by default (version nibble 4, variant `10xx`), lowercase.
- `IdempotencyKey` -- `const new(String value)`, `factory generate([Random? random])` (UUID v4), `==`, `toString` = value. One key per user intent: the intent's state (wizard, form notifier) holds it, sends it with every retry of that intent and generates a new one when the content of the intent changes (the backend answers `422 idempotency_key_reused` to the same key with another body).
- `ApiFailure` -- `sealed class ApiFailure implements Exception` with `String? code` (problem `type`) and `String? detail`; subclasses `NetworkFailure` (no usable answer: offline, timeouts, TLS, cancelled), `UnauthorizedFailure` (401), `ValidationFailure` (422 `validation_failed`, `List<Violation> violations`), `RateLimitedFailure` (429, `Duration? retryAfter`), `NotFoundFailure` (404), `ConflictFailure` (409), `ServerFailure` (5xx, undecodable/unexpected answers: `int? statusCode`, `Duration? retryAfter`), `BusinessFailure` (any other 4xx: required `code`, `int statusCode`). `Violation(propertyPath, message, code?)`. `toString` for diagnostics (no tokens there anyway). Repositories **throw** these (no generic Result, architecture §3); Riverpod's `AsyncValue.error` carries them to the UI, which pattern-matches. Feature domains may add their own sealed failures.

### Failures (`lib/core/errors/api_failure_mapper.dart`, 100%)

`final class ApiFailureMapper { const new({required Clock clock}); ApiFailure fromDio(DioException e); ApiFailure fromResponse({required int? statusCode, required Object? body, required Map<String, List<String>> headers}); }`. Split: the pure model in `shared/domain` (application and presentation of slices need it; rules 1–2, 6), Dio-level mapping here, tonik-level mapping in `core/network/portal_results.dart` (rule 7 keeps `tonik_util` out of `core/errors/`).
- `fromDio`: `badResponse`, or `unknown` with a response → `fromResponse`; `connectionTimeout`, `sendTimeout`, `receiveTimeout`, `connectionError`, `badCertificate`, `cancel`, `unknown` without response → `NetworkFailure`.
- Body: `List<int>` → UTF-8 → JSON; `String` → JSON; `Map<String, Object?>` as is; anything else or invalid → no problem. Problem fields: `type` → code, `detail`, `violations[]` (`propertyPath`, `message`, `code`).
- By status: 401 → `UnauthorizedFailure`; 404 → `NotFoundFailure`; 409 → `ConflictFailure`; 422 with `type == validation_failed` → `ValidationFailure`; 429 → `RateLimitedFailure(retryAfter)`; ≥ 500 → `ServerFailure(statusCode, retryAfter)`; other 4xx → `BusinessFailure(code ?? 'http_<status>', statusCode)`; null, 1xx, 2xx, 3xx → `ServerFailure(statusCode)`.
- `Retry-After` (case-insensitive header): non-negative integer seconds; else an HTTP-date (`HttpDate.parse`) minus `clock.now()`, floored at zero; else null.

### Session (`lib/core/security/`, 100%)

- `TokenPair` -- `accessToken`, `refreshToken`, `DateTime? accessTokenExpiresAt`, `DateTime? refreshTokenExpiresAt` (UTC); `toJson()`/`factory fromJson(Map)` (`FormatException` on a missing/invalid field); `==`; `toString()` → `TokenPair(<redacted>)`.
- `TokenStorage` -- `abstract interface class` with `read()`, `write(TokenPair)`, `clear()`; `SecureTokenStorage(FlutterSecureStorage)` stores the JSON under one key `kiveto.session.tokens` (one write = atomic pair); `read` returns null and deletes the key on corrupt JSON.
- `DeviceIdStore(FlutterSecureStorage, {Random? random})` -- `Future<String> loadOrCreate()`: key `kiveto.device.id`; absent or blank → `uuidV4()` written; any storage exception → an in-memory `uuidV4()` (never throws). Secure storage rather than preferences: one storage, no new package; the iOS keychain keeps it across reinstalls, which suits the backend's device budget signal.
- `enum SessionStatus { signedOut, signedIn }`; `final class SessionManager with ChangeNotifier` (a `Listenable` for go_router): `static Future<SessionManager> restore(TokenStorage)` (never throws; a read exception → signed out); `status`, `TokenPair? tokens`; `Future<void> open(TokenPair)` (the API slice 1 calls after `verifyOtp` `authenticated`, an invitation acceptance or a registration: the newest pair always wins); `Future<void> signOut()` (clears memory then storage; slice 5 calls `POST /auth/logout` first); `Future<bool> replaceTokens({required TokenPair expected, required TokenPair next})` (compare-and-set on the refresh token, used after a refresh); `Future<void> signOutIfCurrent(TokenPair expected)`. Memory first, `notifyListeners()` on every change, then persistence; a persistence exception is swallowed (the session lives in memory; the next start asks to sign in again) with a `debugPrint` that names no value.

### Network (`lib/core/network/`, 100%)

- `ApiConfig` -- `new({required Uri baseUrl, String? hostHeader})`; `baseUrl` is the origin (`http://10.0.2.2:81`), validated (`ArgumentError`: absolute http(s), no path/query/fragment); `String get origin`; `bool isApiOrigin(Uri)` (scheme, host, port).
- Chain of `PortalHttp.dio`, in this order: `StrictStatusInterceptor` (first: `onRequest` sets `validateStatus` to 2xx, or 2xx–3xx when `options.followRedirects` is false), `DevHostInterceptor` (only when `hostHeader != null`), `DeviceIdInterceptor`, `AuthInterceptor`. `PortalHttp.bareDio` = the same transport interceptors without auth, same `HttpClientAdapter`, same `BaseOptions` (connect 15 s, send 30 s, receive 30 s); it carries the refresh call and the retries (a retry through a `QueuedInterceptor`'s own `dio.fetch` deadlocks when it fails: its `onError` would queue behind the one awaiting it).
- `DevHostInterceptor(ApiConfig)` -- `onRequest`: `headers['Host'] = hostHeader` when `config.isApiOrigin(options.uri)`. `onResponse` and `onError` (when a response exists): a 3xx whose `location` parses to host `hostHeader` (case-insensitive, any port) gets scheme/host/port of `baseUrl`, path and query kept (`response.headers.set`).
- `DeviceIdInterceptor(String deviceId)` -- sets `X-Device-Id` unless the request has one (case-insensitive).
- `SessionRefresher(AuthApi)` (the `AuthApi` on a `CustomServer` over `bareDio`) -- `Future<RefreshOutcome> refresh(String refreshToken)`; `sealed RefreshOutcome`: `RefreshSucceeded(TokenPair)` (200 → pair from `SessionTokens`), `RefreshRejected()` (typed 400/401/422, or `TonikError` with a `DioException` carrying a 4xx), `RefreshUnavailable(Object error)` (everything else: network, 5xx, decoding).
- `AuthInterceptor extends QueuedInterceptor` -- `new({required SessionManager session, required SessionRefresher refresher, required Dio retryDio})`. `onRequest`: awaits an in-flight refresh, then, when signed in, sets `Authorization: Bearer <access>` and records the access token sent in `options.extra`. `onError`: acts only on a 401 that carried a token, was not already retried, and whose problem `type` is `token_expired`, `unauthorized` or absent; then gets a fresh pair: if the session's access token differs from the one sent → use the session's pair (another error already refreshed, or a newer pair was opened); else single-flight `_inFlight ??= refresher.refresh(...)`: `RefreshSucceeded` → `session.replaceTokens(expected: sent pair, next: new)` and use `session.tokens` (the newest); `RefreshRejected` → `session.signOutIfCurrent(sent pair)`, `handler.next(err)`; `RefreshUnavailable` → keep the session, `handler.reject` with the refresh's `DioException` re-targeted to the original `requestOptions` (`copyWith`), or a `connectionError` `DioException` when there is none. Retry: same `RequestOptions` (method, data, headers incl. `Idempotency-Key`), new `Authorization`, `extra` retried flag, `await retryDio.fetch(options)` → `handler.resolve(response)`; a `DioException` → `handler.reject(e)`. Exactly one refresh for N concurrent 401s follows from the queue plus the "token changed" check.
- `PortalHttp` -- `factory create({required ApiConfig config, required SessionManager session, required String deviceId, HttpClientAdapter? adapter})` builds both Dios; `CustomServer get server` (`CustomServer(baseUrl: config.origin, serverConfig: ServerConfig<Dio>.client(dio))`, one instance); `void close()` closes both Dios (they share the adapter).
- `PortalFileDownloader(Dio dio, ApiConfig config, ApiFailureMapper failures)` -- `Future<DownloadedFile> download(String apiPath)` (`/api/portal/v1/clinics/{c}/documents/{id}/file`, `…/vaccination-booklet`, `/me/data-exports/{id}/file`): GET with `followRedirects: false`, `ResponseType.bytes`; 2xx → its bytes; 3xx → `Location` (already rewritten in dev) → GET bytes; 3xx without `Location` → `ServerFailure`; a `DioException` → `throw failures.fromDio(e)`. `DownloadedFile(bytes, contentType?, fileName?)` (file name from `Content-Disposition` `filename=`).
- `portal_results.dart` -- `ApiFailure apiFailureOf(TonikResult<Object?, Response<Object?>> result, ApiFailureMapper failures)`: `TonikError` with a `DioException` → `fromDio`; `TonikError` type `network`/`cancelled` → `NetworkFailure`; other `TonikError` → `fromResponse` of its response, or `ServerFailure()` without one; `TonikSuccess` (an undesired variant) → `fromResponse` of its response. `ClinicInstant clinicInstantOf(DateTime wire)` (`wire.isUtc ? Duration.zero : wire.timeZoneOffset`); `LocalDate localDateOf(Date date)`. The slice pattern: `switch (await api.getMe()) { TonikSuccess(value: GetMeResponse200(:final body)) => map(body), final other => throw apiFailureOf(other, _failures) }`.

### DI (`lib/core/di/`, measured)

`core_providers.dart` (Riverpod 3, plain `Provider`s): `apiConfigProvider`, `deviceIdProvider`, `sessionManagerProvider` (throw `UnimplementedError` until `app/bootstrap` overrides them with values read before `runApp`), `secureStorageProvider` (`const FlutterSecureStorage()`), `clockProvider` (`SystemClock`), `apiFailureMapperProvider`, `portalHttpProvider` (`ref.onDispose(http.close)`), `portalServerProvider`, `portalFileDownloaderProvider`. `system_clock.dart`: `SystemClock implements Clock` (`DateTime.now().toUtc()`). `debug_probe.dart`: `termsProbeProvider` (`FutureProvider.autoDispose<String>`: `TermsApi(server).getCurrentTerms()` → `'200 · ${body.version}'`, else `throw apiFailureOf(...)`), used only by the debug gallery. Slices add their providers in `features/*/di.dart` on `portalServerProvider` and `apiFailureMapperProvider`.

### Theme tokens (`lib/shared/presentation/tokens/`, `lib/app/theme/`)
