- (capability) CAP-1 Read-only prerequisite check (make doctor) on Windows 11 Git Bash and macOS, naming the fix for every missing item; fails on a blocker.
- (capability) CAP-2 One-command install from a fresh clone (make install): pinned Flutter through FVM, dependencies, repo-local setup, summary; idempotent.
- (capability) CAP-3 One-command run on an emulator, simulator or device (make start), selecting or booting the device, skipping pub get when pubspecs did not change.
- (capability) CAP-4 List devices, AVDs and simulators (make devices).
- (capability) CAP-5 Opt-in FVM install for the current user only (make install-fvm), official source, checksum verified, PATH line printed not written.
- (capability) CAP-6 Reset generated state (make clean, make reset = clean + install).
- (capability) CAP-7 Flutter project for Android and iOS with package kiveto_mobile and applicationId / bundle id app.kiveto.portal, the ids the backend .well-known files serve.
- (capability) CAP-8 Environment values from a committed template config/env/dev.json.dist; dev.json created by install when missing, git-ignored, passed with --dart-define-from-file by start.
- (constraint) Flutter 3.47.9 / Dart 3.13.7 pinned in .fvmrc (D1); every call goes through fvm flutter / fvm dart, never a global flutter.
- (constraint) Makefile compatible with GNU Make 3.81 (macOS /usr/bin/make): no .ONESHELL, $(file), != or grouped targets; SHELL := bash; logic in scripts/.
- (constraint) scripts/*.sh compatible with bash 3.2: no declare -A, ${v,,}, mapfile, printf '%(…)T', [[ -v ]], empty-array expansion under set -u; LF line endings.
- (constraint) Nothing installed or configured system-wide (D10): only repository-local git config; FVM install is opt-in and user-scoped; never edit PATH or system settings.
- (constraint) Same command contract on Windows 11 (Git Bash) and macOS; iOS targets only on macOS, with an explicit message on Windows.
- (constraint) Make UX of the Symfony repo: step / ok / warn / fail lines, quiet runs logged with timestamps to LOG_FILE (default .make/make.log) showing the target's last 30 lines on failure, V=1, NO_COLOR=1.
- (constraint) Idempotent: no download or pub get when nothing changed; stamps live in .make/ (git-ignored).
- (constraint) Windows: Developer Mode is a blocker in doctor (FVM symbolic links); clone on a UNC path or with spaces is a warning.
- (constraint) No package added beyond what flutter create generates (dependency rule of CLAUDE.md).
- (decision) Validation V1 runs on this Windows 11 machine (Android emulator Medium_Phone_API_37.0); the macOS half of V1 is left to the user on a Mac.
- (assumption) App display name 'Kiveto' until the user provides one (D2 open).
- (assumption) Apple Team ID not needed for simulator builds; left unset until distribution.
- (assumption) make install does not prefetch Gradle, the NDK or iOS pods; the first build downloads them.
- (assumption) flutter create defaults (flutter_lints, analysis_options.yaml, test/widget_test.dart, counter app) stay untouched until phases 3 and 5 replace them.
- (question) Display name of the app and Apple Team ID (D2).
- (note) Non-goals from the input: analyzer config, tests, coverage, hooks, make ci, GitHub Actions (phase 3); API client and make api-* (phase 4); app code, dev Host header, cleartext config (phase 5); native flavors (D11).

- (decision) Options: PLATFORM (default android), DEVICE, EMULATOR, SIMULATOR, ENV=dev, RUN_ARGS (extra flutter run flags), BOOT_WAIT=180 s, V, NO_COLOR, LOG_FILE=.make/make.log, FULL (doctor).
- (decision) install sets core.hooksPath only once .githooks/ exists (phase 3), so phase 2 never points git at a missing folder.
- (decision) install-fvm targets FVM 4.3.2 official release assets, SHA-256 checked against the release digest; Windows %LOCALAPPDATA%\Programs\fvm (same place as the manual install of 2026-11-02), macOS ~/fvm/bin (FVM install script default); refuses when fvm is already on PATH.

- (decision) Platform android-36 missing is a warning (Gradle can fetch it once the licence is accepted); android-sdk-license missing is a blocker.
